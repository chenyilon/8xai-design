# 五官造型 · 五官造型·智能体

功能标识：`facial_features.agent`

通过人物方向让智能体设计五官

先确认：人物用于哪种服装或品牌调性，哪些特征必须保留？

图片用途：

- `modelImages`：人物或模特参考

限制：宫格是一张生成图，自动裁图属于本地后处理

调用 `usage_guide(variant="facial_features.agent")` 读取当前参数、数量限制、编辑状态；
有预设时用 feature_options 查询真实 ID，不在本说明复制参数默认值。
调用 intent_guide 时携带已确认的目标、保留项、方向和图片用途，避免重复追问。
先 batch_plan，再复述总生成数、可能分析费和保存位置；用户明确确认当前计划后才提交一次。
结果用原计划查询和保存，只交付图片；目视检查效果，失败不自动重新生图。
